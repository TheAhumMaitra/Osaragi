## Osaragi Project
Hello, World! Welcome to Osaragi. An advanced TUI Todo List App. 100% free and 100% open source. I created this project using Python and Textual. This project is very intermidate or advanced learns frinedly

# Install this software
You can install this software very easily to your Windows / Mac OS / Linux.
## Pre requirements to run this software
### Linux
1. Python 3.x
2. Textual 6.3.0
3. Python virtual environment
3. Comfortable terminal for running Textual
## Linux
Any Linux distribution support Osaragi.

## Install
### Clone this reppository
```Zsh
git clone "https://github.com/TheAhumMaitra/Osaragi.git"
```
### Go to Osaragi Folder
```Zsh
cd ~/Osaragi
```
### Go to src folder
```Zsh
cd src

```
### Run the file
```Zsh
 textual run main.py --dev
```
Done.....
